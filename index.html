01THE PROBLEM WITH PRESENTING

Spend your time negotiating,
not formatting.

An asset arrives as a PDF, a spreadsheet and loose notes that do not always agree. To present it, someone has to find each figure, compare it across documents, decide what is shown and what is not, and lay out the teaser. None of that is negotiating, yet it is the first thing the other side sees.

  • 01Data scattered across files

    Each figure has to be found, copied and checked against another document.

  • 02Figures that contradict each other

    When two sources disagree, someone has to decide which one holds, and that decision is not always written down.

  • 03A figure you cannot back up

    In front of whoever decides, one figure without a source weakens the rest of the document.

The first impression of a deal is a document. It deserves more than copy and paste.

03AFTER THE PDF

You have the teaser.
Now it has to travel.

Passed from hand to hand, an asset ends up in versions you did not write, in hands you do not know, at a price nobody agreed. Every link in the chain costs you four things.

  1. 01Time

    Every question goes up and down the chain.

  2. 02Information

    The forwarded teaser is a photocopy of a photocopy.

  3. 03Fees

    Each link wants its share, and the deal stops closing.

  4. 04Confidentiality

    The asset circulates without control and arrives burned.

The problem is not intermediaries. It is the links that add nothing: the ones that hold no mandate and only pass messages on. A broker with a mandate comes out stronger.

Say what you hold.

Every asset and every buy mandate declares its position in the operation. The match only crosses pairs that have chosen to work together.

HOW THE MATCH WORKS

A match you can explain,
not a black box.

AI helps structure your documents. The match itself is calculated by transparent rules, so the same asset and the same mandate always produce the same result.

  1. 01Hard filters first

    Asset type, ticket range, mandate position, authorisation from both parties and the buyer’s exclusions. If one fails, there is no match.

  2. 02Only documented data

    The score reads what is documented and sourced in the dossier. What is missing adds nothing: the engine never estimates a figure.

  3. 03A True Fit score

    Each criterion the mandate declares is weighted. A match is proposed from 85% True Fit.

  4. 04Identity later

    Both sides see an anonymous spec sheet. Names and contacts are released only when both approve.

The radar, working in the background

The radar crosses the assets and mandates that each side has authorised for blind matching. It only surfaces matches that reach 85% True Fit, and it shows the zone, never the address.
